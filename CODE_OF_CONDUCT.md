# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolha quem está começando, critique ideias e não pessoas, e lembre que este é um espaço de aprendizado. Assédio, discriminação ou comportamento hostil de qualquer tipo não são tolerados.

Para relatar um problema de conduta, abra uma issue marcada como `conduta` ou entre em contato com as pessoas mantenedoras pelo perfil do repositório. Os relatos são tratados com confidencialidade.
